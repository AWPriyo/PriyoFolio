## About

I'm a Computer Science and Engineering student at **East West University, Dhaka**. This portfolio introduces who I am, the technologies I work with, and my academic and professional journey.

The site is built with plain HTML, CSS, and JavaScript, with no build step required.

## Highlights

- Responsive personal portfolio with a mobile-friendly navigation menu
- Animated hero section with a profile-photo slideshow
- Interactive background themes and particle animation
- Sections for skills, education, experience, activities, references, and contact
- Motion effects that respect the visitor's reduced-motion preference

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/AWPriyo/PriyoFolio.git
   ```

2. Open `index.html` in your browser. Alternatively, open the folder in VS Code and run it with the Live Server extension.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.

After GitHub Pages finishes deploying, the published site URL will appear in the Pages settings.
